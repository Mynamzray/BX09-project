Git Workflow Cheat Sheet
1. Daily Workflow (Syncing your local changes)
git status : Check which files have been modified.

git add . : Stage all changes for the next commit.

git commit -m "Your description" : Save your changes as a local snapshot.

git push : Upload your commits to the remote repository (GitHub).

2. Branching (Switching between Full and Lite versions)
git branch : List all branches.

git checkout -b <branch_name> : Create and switch to a new branch (e.g., git checkout -b lite).

git checkout <branch_name> : Switch between existing branches.

3. Syncing with Remote
git fetch : Download the latest history from the cloud (safe).

git pull : Download and merge remote changes into your local files.
